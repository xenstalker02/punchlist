# Support

Punchlist is a development-preview repository. It is maintained for the current default branch and the documented Python 3.11, Node.js, Playwright, and Chromium workflow. Earlier commits, alternate browser engines, hosted integrations, and private audit environments are outside the compatibility promise.

For a reproducible repository problem, open an issue with the Punchlist commit, operating system, Python and Node versions, the command you ran, expected and actual behavior, and a minimal synthetic input when relevant. Remove credentials, local paths, private URLs, personal emails, customer identifiers, and unapproved screenshots.

Use an RFC for taxonomy, schema, scoring, evaluator-order, or release-process proposals. Use [SECURITY.md](SECURITY.md) for vulnerabilities and confidential exposure, not a public issue. For ordinary report-data handling, follow the authorization and redaction boundary in the [README](README.md#privacy-and-authorization).
